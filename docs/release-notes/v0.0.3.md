utter 0.0.3 lets the host's endpoint bound close a quiet room without a forced word, tells a host which runtime it loaded, and ships its attestation bundle with the release. The decoding output is unchanged unless the new margin is set.

## Added

A floor margin on the host's endpoint bound: `set_endpoint_floor_margin` in Rust, `SetEndpointFloorMargin` in Python, `utter_recognizer_set_endpoint_floor_margin` in C. On a quiet room the model reads the hiss as a word's first phone, no silence rule sees trailing silence, and the 20 s cap then forces the cheapest grammar word onto the stretch. With a margin in dB over the reported floor, a trailing `[speech]` entry within it counts as trailing silence, a rival word within it cannot veto, and the final the bound reaches that way is the path as it stood: an empty word list, the text `[sil]` or `[speech]`, and the new endpoint value `floor`. Off by default and byte-identical when unset. Recorded as TD-12.

`utter_version` and `utter_revision` in the C ABI, static strings naming the crate version and the git commit the library was built from.

## Fixed

`REVISION` reports the commit in a crate built from crates.io; 0.0.1 and 0.0.2 report "unknown" from the registry. The build script reads the commit `cargo package` records when there is no checkout.

Digital silence no longer reads as -999 dBFS. A word entry's `energy_dbfs` is `null` when there is no signal under the word, and `floor_dbfs` is absent while the quietest windows of the last ten seconds are digital silence, so a host gate relative to the floor is not handed a number every word sits above.

## Distribution

The release attaches the Sigstore bundle of its build-provenance attestation, `utter-v0.0.3.sigstore.json`, so an archive verifies offline:

```bash
gh attestation verify utter-linux-x86_64.tar.gz --bundle utter-v0.0.3.sigstore.json --owner pyscape
```
