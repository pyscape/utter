utter 0.0.2 hardens the readers against malformed model files and audio, and ships prebuilt binaries for six platforms. The decoding API and its output are unchanged from 0.0.1.

## Security

The model-file and audio readers no longer panic or allocate from an unchecked length on malformed input. A length or count is checked against the bytes behind it before it sizes an allocation, and an out-of-range id or state is rejected as an error. Six fuzz targets cover the Kaldi reader, the FST reader, the JSON grammar, the transition model, the i-vector extractor and the audio path, and run on every push and for longer weekly. The seven classes of crash the fuzzer first found are fixed, each with a regression test.

## Changed

Narrowing numeric conversions are checked throughout. A negative or out-of-range dimension, word id or state read from a corrupt model file is now an error rather than a wrapped value.

No change to the decoding API or its output: the benchmark per-clip records are identical to 0.0.1.

## Binaries

Release archives for Linux (x86_64 and aarch64), Windows (x86_64 and arm64) and macOS (one universal binary), each with the shared library, the `stream` tool, the C header and the licenses. Windows archives are zips; the Linux libraries link against glibc 2.28, so they load on RHEL 8, Ubuntu 20.04 and Debian 11 and newer. Every archive carries a build-provenance attestation:

```bash
gh attestation verify utter-linux-x86_64.tar.gz -R pyscape/utter
```

## Install

```bash
cargo add utter        # Rust
pip install utterpy    # Python
```
